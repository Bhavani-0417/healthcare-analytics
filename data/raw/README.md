# Local training data

Place the **labeled training CSV** here as `train.csv`. It must contain the target column `Stay`.

The historical notebook refers to a separate training file that is not included in the current GitHub repository. The tracked `Healthcare-Analytics-main/Health50/test.csv` is an unlabeled test file and is not a substitute for the labeled training set.

Obtain the dataset only from a source whose terms permit your intended use. Do not commit patient-identifiable, confidential, or otherwise sensitive data. Local CSV files in this directory are ignored by Git.
