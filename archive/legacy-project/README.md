# Archived legacy project files

This folder preserves the original Streamlit experiments, serialized encoders, and historical test CSV from the initial project layout.

These files are retained for traceability only. The maintained application is the root-level `app.py`, and the maintained ML implementation is under `src/healthcare_los/`.

The old scripts reference missing local files such as `train.csv` and `model.pkl`, and should not be treated as the supported application.
