# Contributing

Thank you for considering an improvement.

## Development setup
1. Create and activate a Python virtual environment.
2. Install development dependencies: `pip install -e ".[dev]"`
3. Run tests: `pytest`

## Pull request checklist
- Keep changes focused and explain the problem solved.
- Add or update tests when behavior changes.
- Do not commit personal, confidential, or unauthorized datasets.
- Do not commit credentials, local environment files, or generated model artifacts.
- Document dataset provenance, target definition, and evaluation method.
- Do not present exploratory metrics as validated clinical performance.

Prefer small functions, descriptive names, and clear error messages.
